# Geophysics Projects

Projects from my B.Sc. in Geophysical Engineering at Institut Teknologi Bandung (2015–2019). They cover signal processing of seismic and radar data, geophysical survey design, and integration of several methods.

## Featured project (separate repository)

| Project | What it is |
|---|---|
| [**Ambient seismic noise tomography of Palu**](https://github.com/fashliadli/ambient-seismic-noise-tomography-palu) | Bachelor thesis, published in *Jurnal Geofisika* (2019): shear-wave velocity structure from continuous seismic noise recorded at 22 stations |

## Skills shown across the projects

- **Signal processing:** filtering, normalisation, cross-correlation, deconvolution, gain, stacking.
- **Quality control:** resolution tests, trade-off analysis, comparison of processing stages, forward models as references.
- **Inversion and modelling:** linear tomography, particle swarm optimisation, 2D gravity and magnetic modelling.
- **Interpretation:** relating geophysical anomalies to geology, and noting what each method cannot resolve.

## About this repository

Each folder has its own README (with the method, results and limitations), a `documentation/` folder with the report or paper, and an `assets/` folder with the figures. Reports are in English or Bahasa Indonesia and are summarised in English in the READMEs. Raw data are not included.

My current data-analysis work (Python notebooks) is in separate repositories, for example [`iot-water-meter-data-analysis`](https://github.com/fashliadli/iot-water-meter-data-analysis).
